# Portfolio Website

This is a simple personal portfolio website created using **HTML**, **CSS**, and **JavaScript**. It showcases basic sections such as About, Skills, Projects, and Contact. The design is responsive and includes a fixed navigation bar, interactive buttons, and form alerts.

## 🧾 Features

- Responsive layout for desktop and mobile devices
- Fixed navigation bar
- About Me section with profile image
- Skills section listing known technologies
- Project cards with images and buttons
- Contact form with basic input validation and alert
- Light touch of interactivity using JavaScript
- Font Awesome icons for social media

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (CDN)

## 📁 Project Structure

/
├── index.html # Main HTML page
├── style.css # Stylesheet for layout and design
├── script.js # JavaScript for interactivity
├── img/
│ ├── portfolio.jpg # Profile image for About section
│ └── img.jpg # Used in project cards
└── settings.json # Live Server settings (optional)


## 🚀 How to Run Locally

1. Clone or download this repository.
2. Make sure the `img` folder contains `portfolio.jpg` and `img.jpg`.
3. Open `index.html` in a browser or use Live Server (recommended for dev).

## ⚠️ Notes

- Ensure all images are placed correctly in the `/img` folder.
- If using VS Code Live Server, port 5501 is set (see `settings.json`).
